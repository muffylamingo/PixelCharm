## Parts (prototype, Phase 1)

| Part | Notes |
|---|---|
| ESP32-S3-DevKitC-1 **N16R8** | 16 MB flash, 8 MB octal PSRAM. A clone works; ours has a CH343 USB-serial chip |
| 1.3" **240×240 IPS ST7789** module | 7 pins (GND VCC SCK SDA RES DC BLK), no CS |
| Jumper wires | 7 female-female for the screen, 2 male-female for the touch buttons |
| USB-C data cable | Some cables only charge |

The keychain itself (a smaller board, a battery, a 3D-printed case) comes in Phase 4.
